# Ring of Red 繁體中文化補丁

《Ring of Red》（SLPM-62013，日版）的繁體中文化 xdelta 補丁。

補丁與 PCSX2 金手指檔請到 [Releases](../../releases) 下載。

## 使用方法

以日版原盤 `Ring of Red (Japan).bin` 為基礎，套用 xdelta 補丁得到繁中版 `Ring of Red (Japan) - TC.bin`：

```
xdelta3 -d -s "Ring of Red (Japan).bin" RingOfRed-zh-patch-V20261120_1.xdelta "Ring of Red (Japan) - TC.bin"
```
